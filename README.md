# 智慧行事曆 LINE Bot (程式設計作業3)

這是一個具備 **生成式 AI 語意解析** 與 **智慧對話狀態管理** 的 LINE 機器人，能協助使用者用自然語言預約任何行程、記錄到 SQLite 資料庫，並提供 Google 行事曆自動建立與雙重提醒功能。

## 🌟 實作功能與亮點 (包含加分題)

1. **Google Gemini 3.5 智慧語意解析 (亮點 1)**：
   - 捨棄傳統的關鍵字判斷，全面導入 Google 最新 Gemini 3.5 Flash 模型。使用者可以用最自然的口語輸入（例如：「我明天晚上8點要去小巨蛋看演唱會」），機器人能精準擷取出「主題」、「時間」、「地點」。完全不限制行程種類！
   - 具備防呆與引導機制，若使用者提供的資訊不齊全，機器人會智慧提示缺少的部分。
2. **SQLite 資料庫整合與狀態管理 (亮點 2)**：
   - 利用 `user_states` 資料表結合 AI 實現「具備記憶的上下文對話」。機器人不會失憶，能分次收集資訊。
   - 利用 `meetings` 資料表將所有建立成功的行程歸檔，留下永久的歷史紀錄。
3. **Google 行事曆 API 全自動整合 (加分題 100分)**：
   - 透過 Google Calendar API 進行伺服器端無縫對接。使用者建立行程後，系統會「全自動」在雲端幫使用者將行程新增到 Google 行事曆，並回傳專屬網址，完全不需要手動填寫！
   - 行程設計為「零時長（0分鐘）」的提醒點，避免佔用整塊時間段。
4. **Email 通知信件**：
   - 預約成功後，系統會透過 Python 內建的 `smtplib` 自動發送一封會議通知 Email。
5. **開會前 2 小時自動提醒**：
   - 使用 `APScheduler` 背景排程器。在使用者設定的時間 **前 2 小時**，系統會同時透過 LINE 推播與 Email 發送「即將開始」的雙重提醒。

## 📱 測試步驟 (給助教)

1. 加入機器人好友 (請在此補上你的 LINE Bot ID 或 QR Code)。
2. 傳送測試語句 A (一次給齊資訊)：
   > `我明天下午5點要去圖書館看書`
   *預期結果：機器人會直接建立行程，並回覆 Google 行事曆的加入連結。*
3. 傳送測試語句 B (故意漏掉資訊)：
   > `我要去洗牙`
   *預期結果：機器人會反問時間與地點。你可以分次回答「下週二下午三點」、「東區牙醫診所」，機器人會自動拼湊並建立。*
4. （測試 2 小時前提醒）：請預約一個距離現在「超過兩小時」的行程，並在兩小時前檢查 Email 與 LINE 是否收到通知。
5. 輸入 `重來`、`取消` 或 `清除` 可以隨時清空對話記憶。

## 🛠 本機執行環境準備

若要在本機端運行此專案：
1. 安裝所需套件：`pip install -r requirements.txt`
2. 建立 `.env` 檔案並填寫：
   ```env
   LINE_CHANNEL_SECRET=你的_SECRET
   LINE_CHANNEL_ACCESS_TOKEN=你的_TOKEN
   GMAIL_USER=你的_GMAIL
   GMAIL_PASSWORD=你的_GMAIL_應用程式密碼
   GEMINI_API_KEY=你的_GEMINI_API_KEY
   ```
3. 確認目錄下有 `credentials.json` 與 `token.json` (用於 Google Calendar API)。
4. 執行主程式：`python app.py`
5. 執行 ngrok：`ngrok http 5000` 並將網址填入 LINE Developer Webhook。
