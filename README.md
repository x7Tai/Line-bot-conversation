# 智慧行事曆 LINE Bot (程式設計作業3)

這是一個具備智慧對話狀態管理的 LINE 機器人，能協助使用者預約會議、記錄到資料庫，並提供行事曆連結與自動提醒功能。

## 🌟 實作功能與亮點 (包含加分題)

1. **智慧對話狀態管理**：
   - 如果使用者只輸入「這週一要開會」，機器人會智慧判斷缺少時間與地點，並主動反問：「請問會議具體是什麼時間？地點在哪裡？」。
2. **SQLite 資料庫整合**：
   - 收集完完整的時間與地點後，會自動將預約資訊存入本機的 SQLite 資料庫 (`bot.db`) 中。
3. **免信用卡 Google 行事曆整合 (加分題 100分)**：
   - 捨棄繁瑣的 Google API 設定，機器人會自動產生一段專屬的 **「Google 行事曆新增連結」**。使用者只需點擊網址，即可在手機或電腦直接開啟預先填寫好時間與地點的行事曆，一鍵儲存。
4. **Email 通知信件**：
   - 預約成功後，系統會透過 Python 內建的 `smtplib` 自動發送一封會議通知 Email 給主辦人。
5. **開會前 2 小時自動提醒**：
   - 使用 `APScheduler` 背景排程器，在預計開會前 2 小時（展示時另有 10 秒後的測試排程），LINE 機器人會主動推播訊息提醒使用者。

## 📱 測試步驟 (給助教)

1. 加入機器人好友 (請在此補上你的 LINE Bot ID 或 QR Code)。
2. 傳送測試語句 A：
   > `這週一要開會`
   *預期結果：機器人會反問時間與地點。*
3. 傳送測試語句 B (補齊資訊)：
   > `下午4點 延平技術大樓817`
   *預期結果：機器人會回覆記錄成功的訊息，並附上 Google 行事曆的加入連結。大約 10 秒後，會收到自動推播的「開會提醒」訊息。*

## 🛠 本機執行環境準備

若要在本機端運行此專案：
1. 安裝所需套件：`pip install -r requirements.txt`
2. 建立 `.env` 檔案並填寫：
   ```env
   LINE_CHANNEL_SECRET=你的_SECRET
   LINE_CHANNEL_ACCESS_TOKEN=你的_TOKEN
   GMAIL_USER=你的_GMAIL
   GMAIL_PASSWORD=你的_GMAIL_應用程式密碼
   ```
3. 執行主程式：`python app.py`
4. 執行 ngrok：`ngrok http 5000` 並將網址填入 LINE Developer Webhook。
